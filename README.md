# 🎵 Spookify App - v1.0.0

## 🚀 Overview

Spookify is a Spotify clone built with Flutter, featuring real-time integration with the Spotify API. It uses the **Bloc (Business Logic Component)** architecture to ensure clean, modular, and scalable code — managing user interactions, API communication, and state across the app.

Key features include:
- Real-time track display from Spotify API
- User Dashboard
- Favorites list
- Track listing by artist/album
- Responsive UI
